# Images-resize

כלי אינטרנט לשינוי גודל תמונות, במקום לעבוד בפוטושופ. הכל רץ בדפדפן, והתמונות לא עולות לשום שרת.

## הפעלה

פותחים את `index.html` בדפדפן, בלחיצה כפולה. לא צריך התקנה.
אפשר גם לפרסם את התיקייה ב-GitHub Pages.

## מה אפשר לעשות

- להעלות תמונות בגרירה, בבחירת קבצים או בהדבקה (Ctrl+V). אפשר כמה תמונות ביחד.
- לבחור גודל מהרשימה, את כל הגדלים ביחד, גודל מותאם (Custom), או להשאיר את הגודל המקורי (רק להמיר, לדחוס או להחליף רקע).
- לבחור מה קורה כשהיחס של התמונה שונה מהגודל:
  - חיתוך (Crop), עם בחירה איזה חלק לשמור
  - התאמה (Fit), כל התמונה נכנסת והשאר ממולא ברקע
  - מתיחה (Stretch)
- לבחור רקע לתמונה: לבן, שחור, שקוף, או כל צבע אחר. הרקע ממלא גם שטחים שקופים בתמונה המקורית, למשל בלוגו PNG.
- להחליף את הרקע הקיים בתמונה. זה מתאים למוצר שצולם על רקע חלק, והרקע מוחלף בצבע שנבחר או הופך לשקוף. יש שלוש עוצמות: עדין, רגיל וחזק.
- לבחור סוג קובץ: JPEG, PNG, WebP או AVIF (אם הדפדפן תומך).
- לבחור איכות: נמוכה, בינונית או גבוהה.
- להגדיר גודל קובץ מקסימלי ב-KB. הכלי מחפש אוטומטית את האיכות הגבוהה ביותר שנכנסת במגבלה.
- להוריד כל תמונה בנפרד, או את כולן כקובץ ZIP.
- ההגדרות האחרונות נשמרות בדפדפן.

## הוספה או שינוי של גדלים

עורכים את הקובץ `presets.js` ומוסיפים שורה:

```js
{ name: "Banner", width: 1200, height: 400 },
```

אפשר להוסיף גם `maxKB: 450` כדי לתת לגודל מסוים מגבלת KB משלו.
