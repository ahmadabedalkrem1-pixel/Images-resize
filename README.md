# Images-resize

כלי אינטרנט לשינוי גודל תמונות, במקום לעבוד בפוטושופ. הכל רץ בדפדפן, והתמונות לא עולות לשום שרת.

ממשק האתר באנגלית. השמות של הכפתורים וההגדרות מופיעים כאן כפי שהם באתר.

## הפעלה

פותחים את `index.html` בדפדפן, בלחיצה כפולה. לא צריך התקנה.
אפשר גם לפרסם את התיקייה ב-GitHub Pages.

## מה אפשר לעשות

- להעלות תמונות בגרירה, בבחירת קבצים או בהדבקה (Ctrl+V). אפשר כמה תמונות ביחד.
- להעלות תיקייה שלמה (כולל תתי-תיקיות), בגרירה או בכפתור "Choose folder".
- להעלות קבצי פוטושופ (PSD). האתר משתמש בתמונה המאוחדת שנשמרה בקובץ. אם הקובץ נשמר בלי "Maximize compatibility", האתר מרכיב את התמונה מהשכבות הגלויות (בלי אפקטים של שכבות).
- לבחור גודל: הגודל המקורי של התמונה, גודל מהרשימה, כל הגדלים ביחד, או גודל מותאם חד-פעמי.
- להוסיף גודל קבוע לרשימה עם "+ Add a new size to the list". הגודל נשמר בדפדפן של מי שהוסיף אותו, ומסומן ב-★. גדלים לכל הצוות מוסיפים בקובץ `presets.js`.
- **הגדרות קבועות לגודל**: ב-`presets.js` אפשר לקבוע לגודל רקע, סוג קובץ, משקל מקסימלי ומיקום, שגוברים על הבחירה באתר.
- **לפני/אחרי**: לחיצה על תוצאה פותחת את המקור והתוצאה זה לצד זה, עם גודל אמיתי ומעבר בין תוצאות.
- **התאמת חיתוך לגודל אחד**: "✂ Crop" בכרטיס התוצאה מאפשר לשנות את החיתוך רק לגודל הזה.
- **עריכת תמונה** (כפתור "✎ Edit" ליד שם הקובץ): חלון אחד עם שלוש לשוניות. עוברים ביניהן בלי לסגור, וכפתור "Save changes" אחד שומר הכול. "Restore original" מחזיר את התמונה למקור.
  - **Crop** – חיתוך, סיבוב ב-90° ויישור. "No crop" מבטל את החיתוך.
  - **Light** – בהירות (Brightness), ניגודיות (Contrast) ורוויית צבע (Colour), עם תצוגה חיה. לחיצה כפולה על מחוון מאפסת אותו. נשמרים רק המספרים, כך שאפשר לחזור ולשנות אותם בלי לאבד איכות. "Use these settings for all images" מחיל אותם על כל התמונות ברשימה.
  - **Remove** – הסרת אובייקטים עם AI: צובעים במברשת את מה שרוצים להעלים, וכשמשחררים את העכבר ה-AI ממלא את האזור לפי מה שמסביב. רק האזור שנצבע משתנה. אפשר לבטל ולחזור (Undo/Redo), להגדיל את התצוגה, ולהחזיק כפתור כדי לראות את המקור.
  - כל העריכות חלות על כל הגדלים שיוצאים מהתמונה.
- **שמות קבצים**: תבנית עם `{name}` `{size}` `{w}` `{h}` `{date}` ב-"Advanced settings".
- **שמירה ישירה לתיקייה** (Chrome ו-Edge), בלי ZIP.
- **בדיקות איכות**: אזהרה כשהתמונה המקורית קטנה מדי לגודל, וסיכום אזהרות מעל התוצאות.
- להעלות קובץ PDF, לבחור עמודים, ולקבל את התמונות שבתוכם באיכות המקורית, או את העמוד כולו כתמונה.
- לשפר איכות עם AI (Real-ESRGAN) תמונות קטנות או באיכות נמוכה שצריך להגדיל. רץ בדפדפן, בלי להעלות את התמונה לשום מקום.
- לבחור רקע: מקורי, לבן, שקוף או צבע אחר.
  - בתמונת מוצר על רקע חלק (לבן, אפור, סטודיו), המוצר תמיד מוצג בשלמותו וממורכז בגודל החדש, עם שוליים אחידים.
    - אם נבחר רקע חדש, הרקע המקורי מוחלף אוטומטית.
    - אם נבחר "Original background", הרקע נשאר, ומורחב לצדדים כשהגודל החדש צריך יותר מקום.
  - בתמונה רגילה (נוף, אנשים), הרקע נשאר, והתמונה ממלאת את כל הגודל עם חיתוך שווה מהצדדים.
- לבחור סוג קובץ: JPEG, PNG, WebP או AVIF (אם הדפדפן תומך).
- לבחור איכות: נמוכה, בינונית או גבוהה.
- להגדיר גודל קובץ מקסימלי ב-KB. הכלי מחפש אוטומטית את האיכות הגבוהה ביותר שנכנסת במגבלה.
- להוריד כל תמונה בנפרד, או את כולן כקובץ ZIP.
- ב-"Advanced settings" אפשר לבחור ידנית איך התמונה ממוקמת בגודל החדש. ברירת המחדל היא "Automatic".

ההקטנה נעשית עם הספרייה [pica](https://github.com/nodeca/pica), שמחדדת את התמונה אחרי ההקטנה, בדומה ל-Bicubic Sharper בפוטושופ.

ספריות נוספות: [ag-psd](https://github.com/Agamnentzar/ag-psd) לקבצי PSD, [pdf.js](https://github.com/mozilla/pdf.js) לקבצי PDF, [Cropper.js](https://github.com/fengyuanchen/cropperjs) לחיתוך, [Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN) עם TensorFlow.js לשיפור האיכות (פרטי הרישיון ב-`vendor/ai/LICENSES.md`), ו-[MI-GAN](https://github.com/Picsart-AI-Research/MI-GAN) עם [ONNX Runtime Web](https://github.com/microsoft/onnxruntime) להסרת אובייקטים (פרטי הרישיון ב-`vendor/inpaint/LICENSES.md`). רכיב ההסרה (כ-40MB) נטען רק בפעם הראשונה שפותחים את החלון, ואחר כך נשמר בדפדפן.

## הוספה או שינוי של גדלים

עורכים את הקובץ `presets.js` ומוסיפים שורה:

```js
{ name: "Banner", width: 1200, height: 400 },
```

אפשר להוסיף גם `maxKB: 450` כדי לתת לגודל מסוים מגבלת KB משלו.

אחרי השמירה לא צריך לעשות שום דבר נוסף, וגם לא להעלות את מספר הגרסה. הגודל החדש מופיע תוך דקה או שתיים, בפעם הבאה שפותחים או מרעננים את האתר. אם יש טעות בקובץ (למשל פסיק או מירכאות חסרים), האתר מציג הודעה על כך וממשיך לעבוד בלי הגדלים המוכנים.

## לוגו ורקע

הלוגו ותמונת הרקע של האתר נמצאים בתיקייה `assets`: `bermad-logo.png` ו-`background.jpg`. כדי להחליף אחד מהם, מעלים קובץ חדש באותו שם. הלוגו צריך להיות בהיר על רקע שקוף, כי הוא מוצג על תמונת הרקע הכהה.

## אחרי כל שינוי בקוד

מעלים את מספר הגרסה בשני מקומות, לאותו מספר (לא נדרש כשמשנים רק את `presets.js`):
- `?v=` בקובץ `index.html` (למשל מ-`v=5` ל-`v=6`)
- הקובץ `version.txt`

האתר בודק את `version.txt` בכל טעינה. אם יש גרסה חדשה יותר, הוא נטען מחדש אוטומטית, בלי Ctrl+F5.
