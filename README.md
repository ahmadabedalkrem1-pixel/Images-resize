# Images-resize

כלי אינטרנט לשינוי גודל תמונות, במקום לעבוד בפוטושופ. הכל רץ בדפדפן, והתמונות לא עולות לשום שרת.

## הפעלה

פותחים את `index.html` בדפדפן, בלחיצה כפולה. לא צריך התקנה.
אפשר גם לפרסם את התיקייה ב-GitHub Pages.

## מה אפשר לעשות

- להעלות תמונות בגרירה, בבחירת קבצים או בהדבקה (Ctrl+V). אפשר כמה תמונות ביחד.
- להעלות תיקייה שלמה (כולל תתי-תיקיות), בגרירה או בכפתור "בחירת תיקייה".
- להעלות קבצי פוטושופ (PSD). האתר משתמש בתמונה המאוחדת שנשמרה בקובץ. אם הקובץ נשמר בלי "Maximize compatibility", האתר מרכיב את התמונה מהשכבות הגלויות (בלי אפקטים של שכבות).
- לבחור גודל: הגודל המקורי של התמונה, גודל מהרשימה, כל הגדלים ביחד, או גודל מותאם חד-פעמי.
- להוסיף גודל קבוע לרשימה עם "+ הוספת גודל חדש לרשימה". הגודל נשמר בדפדפן של מי שהוסיף אותו.
- לבחור רקע: מקורי, לבן, שקוף או צבע אחר.
  - בתמונת מוצר על רקע חלק (לבן, אפור, סטודיו), המוצר תמיד מוצג בשלמותו וממורכז בגודל החדש, עם שוליים אחידים.
    - אם נבחר רקע חדש, הרקע המקורי מוחלף אוטומטית.
    - אם נבחר "רקע מקורי", הרקע נשאר, ומורחב לצדדים כשהגודל החדש צריך יותר מקום.
  - בתמונה רגילה (נוף, אנשים), הרקע נשאר, והתמונה ממלאת את כל הגודל עם חיתוך שווה מהצדדים.
- לבחור סוג קובץ: JPEG, PNG, WebP או AVIF (אם הדפדפן תומך).
- לבחור איכות: נמוכה, בינונית או גבוהה.
- להגדיר גודל קובץ מקסימלי ב-KB. הכלי מחפש אוטומטית את האיכות הגבוהה ביותר שנכנסת במגבלה.
- להוריד כל תמונה בנפרד, או את כולן כקובץ ZIP.
- ב"הגדרות מתקדמות" אפשר לבחור ידנית איך התמונה ממוקמת בגודל החדש. ברירת המחדל היא "אוטומטי".

ההקטנה נעשית עם הספרייה [pica](https://github.com/nodeca/pica), וקבצי PSD נקראים עם [ag-psd](https://github.com/Agamnentzar/ag-psd). היא מחדדת את התמונה אחרי ההקטנה, בדומה ל-Bicubic Sharper בפוטושופ.

## הוספה או שינוי של גדלים

עורכים את הקובץ `presets.js` ומוסיפים שורה:

```js
{ name: "Banner", width: 1200, height: 400 },
```

אפשר להוסיף גם `maxKB: 450` כדי לתת לגודל מסוים מגבלת KB משלו.

## אחרי כל שינוי בקוד

מעלים את מספר הגרסה בשני מקומות, לאותו מספר:
- `?v=` בקובץ `index.html` (למשל מ-`v=5` ל-`v=6`)
- הקובץ `version.txt`

האתר בודק את `version.txt` בכל טעינה. אם יש גרסה חדשה יותר, הוא נטען מחדש אוטומטית, בלי Ctrl+F5.
